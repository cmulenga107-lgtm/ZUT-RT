#ZUT Results Tracker (ZUT-RT)

## Project Overview
Zambia University of Technology Results Tracker (ZUT-RT) is a proposed web-based platform designed for improving the publication, tracking and viewing of student results. Currently, students face delays, lack of transparency, and difficulty accessing results. ZUT-RT proposes a centralized, secure, and user-friendly system where they can view thier results in real time, track academic progress and recieve notifications, while lecturers and administrators can efficiently manage and publish the results

## Assignment Scope
This repository contains the public landing page required. This projet is limited to the design and development of the marketing/informational landing page that introduces the proposed ZUT-RT system, its features, benefits and tean. note:(the actual implimentation is a frontend only).
This landing page demonstrates our understanding of requirements gathering, UI/UX design, and front-end development using HTML5 and CSS3. We did not include the javascript because it was optional.

## Technologies Used

-**HTML5 (Structure):** Used to build the semantic backbone and skeleton of the landing. It handles text layouts, data forms, and native media positioning.
- **CSS3 (Styling & Design):** Used to manage visual aesthetics, color palettes, custom typography, and hover effects. It implements **Flexbox/Grid** for a fully responsive layout that adapts to mobile, tablet, and desktop screens.
